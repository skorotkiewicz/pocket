A few things worth knowing

Before you move in.

Does Pocket work over SSH?

Yes. The Rust SSH server attaches clients to the same tmux session running on your Linux host. Enter the pairing password or use authorized keys. Check the displayed host fingerprint before connecting. For LAN access, follow the listen-address instructions.

Do music and video play on my remote device?

No. Audio playback and external apps run on the host. Text and terminal-block image previews are visible over SSH, but Pocket doesn't stream audio or video to clients.

Will I have to change editors?

No. Press e to open text in $EDITOR, with vi as the fallback. It hands over the terminal while you edit, then brings the file manager back. Press Enter or o if you want the host's default application, even for a folder.

Can I use it without a desktop?

The file manager and SSH server run in a terminal. External graphical apps need a desktop session on the host and a configured file association. Music playback needs a host audio device.

Can I share a session with anyone?

Only people you trust with your host account. SSH users share control and can edit files or open shells with your permissions. Pocket is not a sandbox.
